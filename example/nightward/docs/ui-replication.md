# Nightward UI

1. **设计依据**

   布局与动画时序参照[官方 Nightward](https://goodstuff.pixijs.io/nightward/) 的公开发布脚本。字形、面板、光晕、图标和界面声音使用同源生成资产。

   UI 保留原版两套独立栅格化字形、四种颜色样式。标题和计时器使用双倍字号字形；普通文字使用小字形。没有用拉伸小字形代替原版大字形。

2. **像素比例**

   按原版 `min(devicePixelRatio, 1.5)` 计算 UI 像素密度，再计算 `max(2, round(min(pixelWidth, pixelHeight) / 290))` 的单位与对应图标单位。最终映射到 RMMZ 的游戏坐标，不改变三维渲染分辨率。

   标题与普通界面使用逻辑像素坐标，HUD 的角色血条、伤害数字、Boss 指示和奖励飞行使用世界投影后的游戏坐标。

3. **标题**

   - 原版 Logo、两侧横线与钻石、标语、三项菜单、纪录、胜利纪录、署名和系统按钮。
   - 底部纪录居中分行，署名右对齐置于右下角，保持边距。底部文字采用现有图标单位对应的整数像素字号，并按可用宽度适配；按实际可见行数预留高度后放置菜单，避免胜利纪录与署名重叠或被裁切。底部信息统一沿用原有淡入和退出时序。
   - 字母从 0.1 秒开始落下，单字 0.45 秒、间隔 0.05 秒。
   - 菜单从 0.85 秒开始逐项入场，1.1 秒聚焦 PLAY，2 秒启动扫光与闪烁。
   - 界面内容创建时保持透明，首次 tick 设置动画起点后再显示，避免场景 start 后先渲染默认不透明状态而产生启动闪现；现有入场时间线不变。
   - PLAY 闪白并退出，接一秒的镜头、色调与上下黑边过渡。

4. **HUD**

   - 顶部带边框的经验条、条内等级、经验流光、升级闪白与火花。
   - 带底板的计时器和暂停按钮，击杀/金币面板与获得顺序装备槽。
   - 受伤后在角色脚下显示 22×5 的血条，包含残影、闪白和低血量暗角。
   - 原版大小的伤害数字、暴击字形、弹出提示、新武器和满级通知。
   - 分钟提示、墓穴警告、死神横幅、Boss 血条入场与破碎、离屏指示。
   - 键帽/手柄/触摸移动提示，触摸摇杆使用原版图形。

5. **升级与宝箱**

   默认使用 236×40 的竖排卡片；HUD 下方高度不足时，切换为三列 58 高卡片。卡片保留原版等级标签与初始文案，名称和逐阶说明直接读取对应武器或饰品的原生 `name` / `description`，运行代码不再维护固定文案表。

   在 RMMZ 数据库中编辑各阶记录的「名称」「说明」和图标即可调整卡片。宝箱、装备栏、飞入动画、新武器和满级提示、帮助页、暂停与结算也统一从 `img/system/IconSet.png` 读取原生图标；标题名读取 `$dataSystem.gameTitle`，Boss 血条与结算副标题读取死神敌人的原生名称，菜单确认/取消/光标音效走原生 `SoundManager`。

   升级卡片从 0.12 秒开始错峰滑入，0.45 秒接受选择。选择后播放强调、闪白、其他卡片退场，以及 0.45 秒的图标飞入装备槽。装备槽在图标落下后更新等级。

   宝箱等待 0.6 秒后翻牌展示奖励，1.6 秒后自动收起并依次飞入装备槽。满构筑金币奖励使用角色旁提示。

6. **结算与菜单**

   结算保留 RUN、BUILD、DAMAGE 面板和 RETRY/TITLE。伤害条相对本局最高武器伤害归一化；统计逐项滚数，新纪录盖章并散出火花，构筑逐槽弹入。胜利使用独立延迟、标题入场、日出和音效时序。画面高度不足时，按原版顺序收紧间距、字号与可见伤害行数。

   构筑由 RMMZ 角色的六武器槽与四饰品槽提供。HUD、暂停和结算直接读取装备与阶级；死亡不会清除装备，被动图标和等级无需另存结算快照。

   横屏双栏宽度按可用画面限制为 `min(180, floor((w - 28) / 2))`，保留列间距和两侧边距。

   暂停包含本局统计、构筑、重开/退出确认、设置与说明。设置保留音量刻度、三级震动、伤害数字和全屏。说明保留三页标签与键盘/手柄/触摸分页。

   重开和返回标题使用对角线像素方块擦屏，遮罩期间屏蔽操作。菜单切换消费确认按键的触发状态，保留仍按住的移动键。

7. **实现位置**

   | 文件 | 职责 |
   | --- | --- |
   | `windows/Window_NightwardPanel.ts`、`windows/Window_NightwardSelectable.ts` | RMMZ 窗口皮肤与选择处理 |
   | `primitives/ui.ts`、`sprites/Sprite_Nightward*.ts` | 布局、输入、动效与界面精灵 |
   | `sprites/Sprite_NightwardBuild.ts` | 构筑槽、等级点、升级名称与说明 |
   | `sprites/Sprite_NightwardHud.ts`、`Sprite_NightwardBossBar.ts`、`Sprite_NightwardMoments.ts`、`Sprite_NightwardStick.ts` | HUD 主栏、Boss 血条与指示、阶段横幅/提示/Toast、世界投影飘字、奖励飞行与触摸摇杆 |
   | `windows/Window_NightwardReward.ts` | 升级与宝箱的入场、聚焦、选择和退场 |
   | `windows/` | 标题、暂停、设置、说明与结算各自的面板 |
   | `scenes/Scene_Nightward.ts` | 场景编排、冻结/恢复、纪录与生命周期 |

   RMMZ 的 `Window` 负责菜单按钮、升级卡片、设置/说明、暂停、HUD 面板与结算面板的背景和边框。`Window_Selectable` 负责索引、选项移动、确认、取消、悬停与触摸确认，使用原版不规则排版对应的 `itemRect`。标题、暂停页的系统按钮及 HUD 暂停按钮也使用原生选择窗口。

   字形、扫光、光晕、强调和飞行图标继续使用 Pixi 显示对象，放在原生窗口的内容层中。原有布局、缓动和时间线保持不变。

   `img/system/Window.png` 使用标准192×192分区：背景、普通边框、选中皮肤、箭头、暂停符号和文字调色板。Nightward 的 `Window` 子类读取相同分区并使用原版5像素边角；普通面板和选中面板都来自该文件。调色板与原生箭头/暂停符号保留，面板像素来自原版 UI 生成器。

   只有光晕、细血条、键帽等图形部件继续使用九宫格图集。窗口按原版透明度直接叠加，不使用 WindowLayer 的不透明遮挡规则。RMMZ 继续管理游戏对象、配置、音频和纪录；没有修改引擎或新增依赖。
