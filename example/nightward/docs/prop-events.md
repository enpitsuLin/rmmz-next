# 地图事件驱动的 Prop

1. **绑定当前事件**

   在地图事件的生效页添加“注释”，例如：

   ```text
   <propModel:brazier>
   <propOffset:0.4,0,-0.2>
   <propCollider:model>
   ```

   注释默认绑定所属事件，不填写事件 ID。`propOffset` 为局部 X/Y/Z 偏移；`propCollider:model` 使用预设的全部局部碰撞框。`propCollider:none` 关闭碰撞，也可写 `<propCollider:0,0,1.2,0.8>`，依次为局部 X、Z、宽、深。

   绑定只从当前生效事件页的 108/408 注释读取。切换到没有绑定注释的页面、事件消除或没有有效页面时，模型、碰撞、门体和附属光效一起停用。

2. **编辑器与运行中移动**

   地图原点由 Map001 备注中 `<nightward:...>` 的 `center` 指定，当前为 90。

   ```text
   世界 X = 事件 _realX - center + offsetX
   世界 Y = offsetY
   世界 Z = 事件 _realY - center + offsetZ
   ```

   在 MZ 编辑器拖动事件并保存，重新载入地图后会使用新位置。运行中原生“设置事件位置”和“设置移动路线”直接驱动同一个 Game_Event；读取 `_realX/_realY` 保持移动过程平滑。模型、多框碰撞、火焰、灯光、余辉、蜡烛和建筑门体都使用同一位置。

   火盆生命和破坏时间保存在该事件的 `_nightwardProp` 状态中。复制事件会得到独立状态；切换到另一种模型时初始化该模型状态，新一局重建地图事件时重置。

3. **资源预设**

   | 名称 | 资源 |
   | --- | --- |
   | `brazier` | 火盆、原版碰撞、火焰和灯光 |
   | `monument` | 中央纪念碑、多框碰撞和蜡烛 |
   | `crypt` | 墓穴、碰撞、双扇门和附属光效 |
   | `ruin` | 废墟建筑、多框碰撞、窗光和蜡烛 |
   | `tomb` | 第一种墓碑的别名 |
   | `tree` | 第一种院内枯树的别名 |
   | `fence` | 第一段围栏的别名 |
   | `collider` | 只提供自定义碰撞的空模型 |

   原版各个墓碑、院内树木和围栏保留独立变体，名称分别为 `tomb-0001`、`tree-0001`、`fence-0001` 等；完整预设见资源清单的 `propModels` 和 `propAliases`。没有原版碰撞的装饰预设允许空碰撞数组。

   原作共有 1,063 个可摆放物件。考虑 [MZ 编辑器单图 999 个事件的上限](https://www.tyruswoo.com/rpg-maker/mz/event-generator-mz/event-generator-plugin-v1-0-for-rpg-maker-mz/)，外圈墓碑按区域形成 `tomb-cluster-0001` 等组合预设，保留单体预设和全部原始几何。当前默认布局使用 819 个事件；拖动组合事件时，整组墓碑和蜡烛一起移动。可以用单体预设自行布置独立事件。

   原始几何、材质组、顶点色、UV、局部碰撞和光源由官方生成器直接拆分，继续共用 `world.bin` 数据包。地面、道路、散落碎石和地图外边界树林保留为静态环境。可摆放模型使用局部坐标，不在环境网格中重复绘制。

4. **渲染与原生事件**

   Prop 按材质合批，移动或停用时只更新对应顶点和相关材质的位置缓冲；模型种类或事件绑定变化时重建批次。没有为每个墓碑创建一套独立绘制调用。

   原生 `$gameMap.update(true)` 负责页面刷新、移动路线、自动执行、并行事件和地图解释器。公共事件由这个解释器统一消费，原有独立解释器不再重复读取公共事件队列。暂停或奖励选择时，事件和世界模拟一起冻结。

   世界碰撞仍使用现有连续空间算法。事件位置、有效页或碰撞绑定改变后，更新局部碰撞的世界位置并重建空间索引；建筑的多个框作为同一事件的附属碰撞一起移动。

5. **保留手工布局**

   正常 `generate:content` 保留已有 Map001 和 MapInfos，不重写坐标、备注、注释、条件页、移动路线或手动增删的事件。资源生成只更新资源与预设清单，不重新布置地图。

   新地图不存在时才用原版布局初始化。旧工程的一次性迁移命令为：

   ```sh
   node scripts/prop-layout.mjs
   ```

   当前工程已执行迁移。原有可匹配事件保留 ID、编辑器坐标和页面内容，在第一页补充绑定；缺少对应事件的模型添加为新事件。仅清理完全未改动、已被模型预设替代的重复自动碰撞标记；手改碰撞标记保留为独立碰撞事件。迁移完成后重复调用会保留布局。

   远景组合只合并完全未改动的自动生成事件，并把超出编辑器范围的自动事件放回空闲 ID；手改坐标、页面或备注的事件不参与自动重排。新建地图直接使用组合布局，普通内容生成不执行这类重排。

   只重新制作静态环境和模型预设：

   ```sh
   node scripts/import-reference-assets.mjs --world-only
   ```
